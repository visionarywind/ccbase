# Information
- CMake multi-module project
- Tests via `GTest`
- Algo implements

## Description 
Base project for learning c++

## Structure
- application
  main function
- common
  common lib
- gtests
- test
- libs
- tools
- ascend
  test lib with AsecndCL

## Build
```bash
./build.sh --clean
```

Run tests:
```bash
./run_tests.sh
```

## Run application

```bash
./build/application/app
```
